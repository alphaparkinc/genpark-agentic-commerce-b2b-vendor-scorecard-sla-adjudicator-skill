## 🛠️ MCP Tools Exposed
- `compute_vendor_otif_compliance_score`: Calculate On-Time In-Full (OTIF) percentage and supplier defect Parts-Per-Million (PPM).
- `adjudicate_contractual_sla_financial_penalty`: Adjudicate SLA liquid damages penalty for PO breach under standard master purchasing agreement.
